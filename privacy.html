Privacy Policy

N7OS · Last updated: 12 October 2026

Who this applies to

N7OS is a private, single-owner application. It runs on the owner's own computer and is used only by its owner. It is not offered to the public, and it has no other users.

What data N7OS accesses

With the owner's explicit consent, N7OS connects to the owner's Google account through the Gmail API with read-only access (https://www.googleapis.com/auth/gmail.readonly). It reads only the messages the owner has marked with a dedicated Gmail label, so they can appear in the owner's N7OS inbox.

N7OS does not send, delete or modify email under this access.

How the data is used

  • Messages are shown to the owner and can be turned into the owner's own tasks or notes.
  • Data is used only to provide these features to the owner. It is not sold, not used for advertising, and not used to build profiles.
  • Data is not used to train generalized AI or machine-learning models.

Storage and sharing

  • Data is stored locally on the owner's own computer, on an encrypted disk. Backups are kept locally; no cloud storage is used.
  • Data is not shared with or transferred to any third party.
  • OAuth tokens are stored only on the owner's computer and are never published.

Google API Services User Data Policy

N7OS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The owner can delete stored messages from N7OS at any time.
